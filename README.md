# Student Fee and Scholarship Analysis (Excel)

## Overview
An Excel project that analyzes student fees, installment payments and scholarships across courses and locations. It includes a cleaned dataset, formula-based summary tables and a dashboard.

## Dataset
Self-created sample dataset of 100 students with 20 courses and 10 locations. Columns include student ID, course, location, full fees, number of installments, payment status, admission date and scholarship amount. No real student data is used.

## Files
- student_fee_analysis.xlsx: cleaned dataset with summary tables and dashboard
- student_dataset.xlsm: original working file with pivot tables

## Data Cleaning
- Removed extra spaces from names and course names
- Corrected column names and spelling
- Gave every student a unique ID

## What I Did
- Calculated payment status with an IF formula
- Built course-wise, location-wise and payment summaries using COUNTIF, SUMIF and AVERAGEIF
- Split course fees into three installments
- Built Pivot Tables for course-wise fees and scholarships
- Created a dashboard with KPI cards and charts

## Key Insights
- Total fees across 100 students: Rs 1,12,67,000
- Total scholarship given: Rs 21,78,000, about 19% of total fees
- 81 students received a scholarship
- 14 students paid full fees and 86 are paying in installments
- Machine Learning and Artificial Intelligence are the highest fee courses

## Tools Used
Microsoft Excel (Pivot Tables, formulas, charts)
